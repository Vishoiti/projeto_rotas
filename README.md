⚛️ ***Projeto de Estudo em React***

Projeto simples desenvolvido para praticar os conceitos básicos de React, incluindo criação de componentes, rotas, instalação de dependências e versionamento com Git.

------------------------------------------------------------------------------------------------------------------------------------------------------------------------

**📚 O que aprendi:**

- Criação de projeto React e instalação de dependências
  
- Componentes e organização de arquivos
  
- Navegação entre páginas com React Router
  
- Versionamento de código com Git e GitHub

------------------------------------------------------------------------------------------------------------------------------------------------------------------------

**🛠️ Tecnologias:**

- React

- React Router

- Git
